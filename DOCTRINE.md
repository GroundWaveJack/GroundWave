# Architectural doctrine

These are adopted constraints. Changes require an architecture decision record (ADR) or request for comments (RFC).

1. Groundwave is not one protocol.
2. Reticulum is an important supported profile, not the entire platform.
3. The core preserves human intent, identity, policy, provenance, and security.
4. Ordinary relays forward opaque encrypted payloads whenever possible.
5. Only explicit trusted gateways translate carriage or representation.
6. Lossy translation is declared and auditable.
7. Originals are preserved when policy, safety, and storage permit.
8. Groundwave owns the missing connective layer.
9. Solved layers use open standards and mature open-source projects.
10. Contribute upstream before forking.
11. Competing standards are supported through profiles and adapters.
12. Unsupported semantics and translation loss are explicit.
13. No walled garden.
14. No required centralized service.
15. No vendor, carrier, cloud, radio, package, or application is mandatory.
16. Hardware embodiments are reference implementations.
17. Graceful degradation is mandatory.
18. Best effort does not authorize uncontrolled flooding, surveillance, or unsafe behavior.
19. Privacy, resource limits, regulation, airtime fairness, and owner sovereignty are hard constraints.
20. Future ambition never appears as present implementation.
