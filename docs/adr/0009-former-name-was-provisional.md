# ADR 0009: Former name was provisional

**Date:** 2026-07-14

**Decision owner:** Jack

**Status:** superseded

**Supersedes / superseded by:** Superseded by [ADR 0010](0010-adopt-harriet-as-public-project-name.md).

**Related RFC:** [RFC 0001](../rfc/0001-adopt-harriet-name.md)

## Decision

The former working name remained provisional to avoid premature repository, package, and community disruption. This decision did not select a replacement.

This historical decision was superseded on 2026-07-14 when [ADR 0010](0010-adopt-harriet-as-public-project-name.md) adopted Harriet as the public project name. [ADR 0011](0011-complete-harriet-identifier-migration.md) later completed the controlled identifier migration.

## Consequences and limitations

The provisional-name period prevented an unreviewed identifier migration. No permanent naming, trademark, repository migration, or compatibility commitment followed from this ADR.

## Review trigger

The naming decision was completed by [RFC 0001](../rfc/0001-adopt-harriet-name.md); [RFC 0003](../rfc/0003-complete-harriet-identifier-migration.md) and [ADR 0011](0011-complete-harriet-identifier-migration.md) later authorized the controlled identifier migration.
