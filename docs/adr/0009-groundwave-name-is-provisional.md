# ADR 0009: Groundwave is a provisional name

**Date:** 2026-07-14

**Decision owner:** Jack

**Status:** adopted

**Supersedes earlier scope:** No — formalizes the legacy working name as provisional.

**Related RFC:** None; originating maintainer directive.

## Decision

“Groundwave” remains the legacy working name to avoid premature repository, package, and community disruption. This decision does not select a replacement.

## Consequences and limitations

Documentation may use the working name, but no permanent naming, trademark, repository migration, or compatibility commitment follows from it.

## Review trigger

Begin a separate rename RFC only when conflict, accessibility, community, or migration evidence justifies choosing and evaluating a public replacement.
