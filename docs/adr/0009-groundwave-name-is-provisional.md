# ADR 0009: Groundwave is a provisional name

**Date:** 2026-07-14

**Decision owner:** Jack

**Status:** superseded

**Supersedes / superseded by:** Superseded by [ADR 0010](0010-adopt-harriet-as-public-project-name.md).

**Related RFC:** [RFC 0001](../rfc/0001-adopt-harriet-name.md)

## Decision

“Groundwave” remains the legacy working name to avoid premature repository, package, and community disruption. This decision did not select a replacement.

This historical decision was superseded on 2026-07-14 when [ADR 0010](0010-adopt-harriet-as-public-project-name.md) adopted Harriet as the public project name. Groundwave remains relevant as a historical term and within legacy repository identifiers.

## Consequences and limitations

The provisional-name period prevented an unreviewed identifier migration. No permanent naming, trademark, repository migration, or compatibility commitment followed from this ADR.

## Review trigger

Completed by [RFC 0001](../rfc/0001-adopt-harriet-name.md). Any live identifier migration remains a separate stop-condition decision.
