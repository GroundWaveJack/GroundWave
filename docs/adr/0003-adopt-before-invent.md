# ADR 0003: Adopt before inventing

**Date:** 2026-07-14

**Decision owner:** Jack

**Status:** adopted

**Supersedes earlier scope:** No — retains and broadens the original upstream-first principle.

**Related RFC:** None; originating maintainer directive.

## Decision

Groundwave will adopt, profile, integrate, or contribute upstream before creating a protocol or fork. New work requires a demonstrated gap, layer analysis, interoperability plan, maintenance owner, and exit criteria.

## Consequences and limitations

This reduces fragmentation and maintenance burden but may constrain idealized designs or delay local implementation while upstream paths are evaluated.

## Review trigger

Reconsider a specific adopt-versus-build choice when documented evidence shows upstream options cannot meet required semantics, security boundaries, or maintenance needs.
