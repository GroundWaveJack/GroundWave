# RF and antennas

RF modules and antennas are regional profiles. Documentation must identify band, certification assumptions, conducted power, antenna gain, duty cycle, connector loss, exposure, coexistence, and test configuration. “Compatible” does not imply lawful operation.

Module-owned RF paths prevent a generic expansion bay from silently becoming a broadband RF backplane. Transmit features default off until profile, region, and hardware are known.

Each regional evidence package identifies jurisdiction, device and radio revisions, firmware and settings, frequency plan, occupied bandwidth, conducted and effective radiated power, antenna model and placement, feed-line loss, spurious emissions, receiver performance, duty-cycle controls, exposure assumptions, and applicable authorization. Enclosure or antenna changes invalidate affected evidence until reviewed.

Bench, conducted, and radiated results must state equipment, calibration, setup photographs or diagrams, environment, uncertainty, and raw artifacts. Coexistence tests exercise simultaneous or adjacent operation with onboard Wi-Fi, Bluetooth, Global Navigation Satellite System reception, displays, switching regulators, and other installed radios. Nothing in this documentation authorizes transmission.
