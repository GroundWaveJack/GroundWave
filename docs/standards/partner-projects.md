# Partner-project posture

Groundwave should approach upstream communities with concrete profiles, test fixtures, bug reports, and patches. “Partner” means active coordination only after mutual acknowledgement; this repository currently documents candidates, not formal partnerships.

Reticulum, LXMF, RNode, Sideband, Haven MANET, MeshCore, Meshtastic, DTN implementations, Babel, OpenWrt, LibreMesh, Freifunk Gluon, and AREDN retain independent identities and governance. Compatibility claims require versioned evidence.
