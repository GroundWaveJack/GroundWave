# Ecosystem coordination posture

**State:** adopted doctrine; candidates under evaluation

Groundwave should approach upstream communities with concrete profiles, test fixtures, bug reports, and patches. **PARTNER** means active coordination after mutual acknowledgement. Every project named here is currently a candidate, not a formal partner, unless a later decision record links evidence from both parties.

Reticulum, LXMF, RNode, Sideband, Haven MANET, MeshCore, Meshtastic, delay-tolerant networking implementations, Babel, OpenWrt, LibreMesh, Freifunk Gluon, and AREDN retain independent identities and governance. Groundwave does not speak for, endorse, or imply endorsement by them. Compatibility claims require a named Groundwave-owned profile or adapter, versioned fixtures, test results, and an explicit maturity state.

Current project status, interfaces, naming, governance, and licensing must be externally verified before outreach or implementation. No such review is asserted by this page.
