# Glossary

## Evidence vocabularies

**Project maturity:** **Vision** is a desired outcome; **Adopted doctrine** is a governing constraint; **Architecture under design** has no conforming implementation; **Reference design** is an embodiment for evaluation; **Prototype** is assembled or executable but incompletely validated; **Tested** has recorded results; **Qualified** meets published criteria for a named profile; **Released** is versioned and supported under the release policy.

**Hardware qualification:** **Reference** is a documented example; **Qualified** passed criteria for a named configuration and revision; **Compatible** is expected to meet an interface without completed qualification; **Community-tested** has third-party evidence; **Experimental** is investigatory; **Deprecated** is retained only for migration; **Unsupported** is outside maintained configurations.

**Ecosystem posture:** **OWN** specifies missing Harriet connective semantics; **PROFILE** maps them to an external standard; **INTEGRATE** connects an upstream implementation; **PARTNER** coordinates upstream; **WATCH** makes no compatibility commitment; **DO NOT BUILD** excludes reinvention from project scope.

These vocabularies answer different questions. A PROFILE posture is not a maturity claim, and a released document does not qualify hardware.

- **Harriet:** the adopted public project and platform name, honoring Harriet Tubman under the commitments in `WHY_HARRIET.md`; not a settled package, executable, repository, or protocol identifier.
- **Red Distress:** a predefined authenticated emergency intent with bounded persistent delivery until an authorized stop condition or expiry; not a claim of connection to emergency services.
- **Deployable relay:** an incident-placed node that extends a bounded path into an obstructed or disconnected environment and reports link uncertainty and partitions.
- **Harriet marker:** a small incident-scoped person, group, responder, asset, hazard, or waypoint marker with temporary identifiers, explicit location evidence, and bounded reporting.
- **Base:** a larger owner-controlled node that can contribute bounded storage, power, bandwidth, radios, or uptime.
- **Communication envelope:** intent, policy, capability, representation, delivery, and provenance data for an exchange.
- **Custody:** an authenticated, bounded commitment to retain and attempt forwarding; not proof of final delivery.
- **Edge:** a sender or recipient device where human intent and content authority reside.
- **Home relay:** an explicitly declared relay relationship, not an inferred location or tracking record.
- **Profile:** a reproducible mapping between Harriet semantics and an external standard or project.
- **Representation:** an encoding or derivation such as video, audio, image, text, or acknowledgment.
- **Translation receipt:** auditable provenance for a transformed representation.
- **Zack:** provisional name for the retro handheld reference embodiment; not the platform itself.
