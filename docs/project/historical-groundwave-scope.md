# Historical Groundwave scope

The April 2026 documents framed Groundwave as a Reticulum-based emergency and survival hardware kit with four tiers: Ghost, Brick, Anchor, and FieldNode. They also recorded exact radios, channels, computer modules, security tools, and fiscal/governance plans as if selected.

That work remains useful design history, especially its commitments to open source, graceful degradation, upstream collaboration, pseudonymous contribution, fork rights, and honest limitations. It is superseded as the platform definition because it tied the project too tightly to one protocol, threat narrative, hardware taxonomy, and untested component set.

The FieldNode repository remains an experimental reference. “Brick” and “Anchor” descriptions in placeholder repositories conflict with both the old canonical documents and the current reframe; they have no adopted architectural meaning.
