# Terminology and rename

Groundwave is the provisional legacy working name. No replacement is selected. “Rosetta” is a private design metaphor, not an approved public name. Zack names the handheld reference concept; Base names a resource-contributing node; neither defines the platform.

A rename RFC must assess conflicts, accessibility, cultural meaning, package and repository migration, redirects, compatibility identifiers, trademarks, and community input. Repository and account renames remain stop conditions.
