# Terminology and staged naming migration

**State:** Adopted public name and migration constraints.

**Harriet** is the public project and platform name, adopted in [RFC 0001](../rfc/0001-adopt-harriet-name.md) and [ADR 0010](../adr/0010-adopt-harriet-as-public-project-name.md), in honor of Harriet Tubman. See [Why Harriet](../../WHY_HARRIET.md) for the plain-language explanation and permanent stewardship obligations.

**Groundwave** is the former public working name and remains a historical term and legacy repository name. Preserve it in archives, audit evidence, repository identifiers, Git commands, external-resource names, and explicit historical discussion. `GroundWaveJack/GroundWave` currently hosts Harriet; that fact does not make Groundwave the current project name.

A preliminary search found no same-category adaptive or decentralized communications platform named Harriet, but found unrelated bare-name software uses, including the Rust `harriet` crate and an older Perl daemon-test manager. This is not trademark or availability clearance.

Repository, organization, domain, executable, package, crate, module, and protocol identifiers remain unresolved. Any identifier migration requires separate availability, trademark, compatibility, redirect, accessibility, and rollback review. “Rosetta” remains a private design metaphor, not a public name. Zack and Base name reference concepts, not the platform.
