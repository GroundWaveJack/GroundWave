# Terminology and identifier migration

**State:** Adopted public name and controlled identifiers.

**Harriet** is the public project and platform name, adopted in [RFC 0001](../rfc/0001-adopt-harriet-name.md) and [ADR 0010](../adr/0010-adopt-harriet-as-public-project-name.md), in honor of Harriet Tubman. See [Why Harriet](../../WHY_HARRIET.md) for the plain-language explanation and permanent stewardship obligations.

**Former working name** and **pre-Harriet identifier** are neutral descriptions for earlier naming. The literal identifier is preserved in Git history and the rollback tag, not current tracked content. `HarrietProject/Harriet` is canonical; satellite repositories use `harriet-*`.

A preliminary search found no same-category adaptive or decentralized communications platform named Harriet, but found unrelated bare-name software uses, including the Rust `harriet` crate and an older Perl daemon-test manager. This is not trademark or availability clearance.

The account and repository migration is governed by [RFC 0003](../rfc/0003-complete-harriet-identifier-migration.md). Domain, package-registry, external contract, and protocol availability remain unresolved and require separate compatibility and clearance work. “Rosetta” remains a private design metaphor, not a public name. Zack and Base name reference concepts, not the platform.
