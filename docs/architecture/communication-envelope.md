# Communication envelope

The proposed envelope carries identifiers and versioning; sender and recipient capability references; payload manifests and digests; delivery policy; transformation authority; provenance; and acknowledgment requirements. Mutable forwarding state is separated from signed intent so relays cannot rewrite meaning.

Sensitive capability and reachability data should be minimized, scoped, and expired. Canonical encoding, signature binding, disclosure tiers, and size limits remain open. Schema fixtures are a prerequisite for implementation claims.
