# Architecture overview

Groundwave is a connective layer between human intent and independently evolving carriage systems. Endpoints create communication envelopes; planners choose policy-compliant paths and representations; adapters map to external transports; relays and caches contribute bounded resources; recipients return evidence appropriate to the requested acknowledgment.

The design borrows cryptography, codecs, routing, storage, radio, and delay-tolerant protocols. It owns semantic preservation, policy separation, provenance, profile contracts, and cross-profile conformance.

The whole architecture is under design. Limits include absent schemas, untested planner behavior, metadata leakage, adapter mismatch, and no demonstrated implementation.
