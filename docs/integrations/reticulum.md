# Reticulum profile

**State:** adopted profile target; architecture under design

Reticulum is the adopted target for the first constrained-communications profile, while the profile itself remains under design. LXMF, RNode, and Sideband are related integration candidates with independent scopes. A Harriet-owned profile must map identities, destinations, payload limits, acknowledgments, propagation behavior, confidentiality, and unsupported delivery semantics against externally verified interfaces.

Harriet does not maintain these upstream projects and makes no current conformance claim. Conformance will require a versioned profile, fixtures, interoperability results, and documented negative cases. Custody, representation receipts, and the complete communication envelope belong in an adjacent Harriet layer unless verified upstream extension points support them without breaking interoperability.
