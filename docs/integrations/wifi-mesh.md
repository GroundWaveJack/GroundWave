# Wi-Fi mesh

**State:** proposed integration profile; not implemented

IEEE 802.11s, batman-adv, Babel, and community firmware address different layers and must not be mechanically combined. A Groundwave-owned deployment profile should select one verified link and routing arrangement, publish administrative boundaries and metrics, and test roaming, partition recovery, congestion, multicast containment, and security. Relevant specifications, supported interfaces, and operational assumptions require external verification.

Local-LAN communication should remain useful without ISP transit. A city-wide broadcast domain is explicitly out of scope.
