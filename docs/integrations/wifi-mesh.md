# Wi-Fi mesh

IEEE 802.11s, batman-adv, Babel, and community firmware solve different layers and must not be mechanically combined. A profile should select one link/routing arrangement per deployment, publish administrative boundaries and metrics, and test roaming, partition recovery, congestion, multicast containment, and security.

Local-LAN communication should remain useful without ISP transit. A city-wide broadcast domain is explicitly out of scope.
