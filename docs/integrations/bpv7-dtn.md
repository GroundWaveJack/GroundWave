# BPv7 and delay-tolerant networking

**State:** proposed evaluation

BPv7 offers standardized bundles and convergence-layer adaptation for disrupted paths; BPSec provides bundle security mechanisms. Evaluation must cover identity binding, metadata exposure, fragmentation, custody or status evidence, constrained encoding, expiration, duplicate suppression, and interoperability with maintained DTN implementations.

Groundwave will not create another bundle protocol. Adoption awaits fixtures and threat analysis.
