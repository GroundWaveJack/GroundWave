# BPv7 and delay-tolerant networking

**State:** proposed profile and integration evaluation; not implemented

Bundle Protocol Version 7 (BPv7) and Bundle Protocol Security (BPSec) are candidates for disruption-tolerant carriage and protection. Their exact semantics, extension points, implementation status, and fit must be checked against authoritative specifications and selected implementations before adoption. Evaluation must cover identity binding, metadata exposure, fragmentation, custody or status evidence, constrained encoding, expiration, duplicate suppression, and interoperability.

Groundwave will not create another bundle protocol. Adoption awaits an owned mapping profile, fixtures, threat analysis, and repeatable interoperability evidence.
