# OpenWrt

**State:** proposed first router target

An OpenWrt edge could provide local discovery, bounded relay/cache, transport adapters, and owner policy without requiring ISP transit. A profile needs supported releases and architectures, package size, memory/storage budgets, reproducible builds, secure updates, rollback, firewall behavior, and an automated test matrix.

No package exists. LibreMesh, Gluon, and AREDN integration should be coordinated rather than assumed.
