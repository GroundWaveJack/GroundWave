# OpenWrt

**State:** proposed first router target; no implementation

An OpenWrt edge could provide local discovery, bounded relay/cache, transport adapters, and owner policy without requiring Internet service provider transit. A Harriet-owned package profile would need an externally verified target matrix, package size, memory and storage budgets, reproducible builds, secure update and rollback behavior, firewall behavior, and automated tests.

No package or qualified router profile exists. LibreMesh, Gluon, and AREDN are integration or partnership candidates; coordination must not be assumed without mutual acknowledgement. Current interfaces and project policies require external verification before design commitments.
