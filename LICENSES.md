# Licensing map

The project records the following **licensing intent**:

- hardware source: CERN Open Hardware Licence Version 2 — Strongly Reciprocal;
- software: GNU Affero General Public License Version 3;
- documentation: Creative Commons Attribution-ShareAlike 4.0 International.

This repository does not yet contain complete canonical license texts or reliable per-file declarations. The GitHub repositories are therefore not consistently licensed despite earlier prose claims. This branch does not select, change, or cure licensing terms.

Before accepting reusable source, maintainers should add reviewed canonical texts, define file boundaries, and confirm compatibility. Contributors must not assume this page alone grants permissions. The `groundwave-fieldnode` repository carries its own existing license file and requires a separate review.
