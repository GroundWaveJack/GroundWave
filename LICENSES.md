# Licensing map

The project records the following **licensing intent**:

- hardware source: CERN Open Hardware Licence Version 2 — Strongly Reciprocal;
- software: GNU Affero General Public License Version 3;
- documentation: Creative Commons Attribution-ShareAlike 4.0 International.

This repository does not yet contain complete canonical license texts or reliable per-file declarations. The GitHub repositories are therefore not consistently licensed despite earlier prose claims. This branch does not select, change, or cure licensing terms.

The words “intent,” “hardware source,” “software,” and “documentation” do not establish reliable file boundaries. Mixed artifacts, generated outputs, third-party material, examples, and contributions also lack a documented treatment. Existing history must not be relabeled retroactively without appropriate review and contributor authority.

Before accepting reusable source, maintainers should add reviewed canonical texts, define file boundaries, inventory third-party material, and obtain appropriate licensing review. Contributors must not assume this page alone grants permissions. The `groundwave-fieldnode` repository carries its own existing license file and requires a separate review. Resolution is a stop-condition decision under [governance](GOVERNANCE.md), not routine cleanup.
